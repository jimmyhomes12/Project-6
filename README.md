# Project-6: E-commerce Analytics Warehouse & Power BI

This repository contains an end-to-end e-commerce analytics project with two main parts:

1. A PostgreSQL mini data warehouse using a star schema, ETL scripts, quality checks, and tests
2. A Power BI report and semantic model built on top of the warehouse

## Repository structure

- `/Data_Management/Ecommerce_Mini_Warehouse_Postgres`
  - SQL DDL/ETL scripts
  - source CSV data
  - data quality checks
  - automated pytest validation
  - warehouse documentation and Power BI setup guide
- `/Ecommerce.SemanticModel`
  - Power BI semantic model definition
- `/Ecommerce.Report`
  - Power BI report definition
- `/Ecommerce.pbip`
  - PBIP project file linking report/model artifacts
